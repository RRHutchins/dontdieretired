# Don't Die Retired puzzle books

Print-on-demand puzzle books for Amazon KDP, generated by program.

    pip install ortools reportlab wordfreq english-words pillow
    python books/build_book.py vol1 hard     # interiors and covers into books/out/
    python books/verify.py vol1 hard         # independent check of every puzzle; exit code 0 means all passed

| File | What it does |
|---|---|
| `puzzles.py` | One generator per puzzle type. Every logic puzzle is proved by a solver to have exactly one solution before it is used. |
| `layout.py` | Draws each type, as a puzzle or as its solution. |
| `content.py` | Themed word lists, cryptogram lines (proverbs and out-of-copyright works only), instructions. |
| `build_book.py` | The books (`BOOKS`), page layout, wraparound cover sized to the page count. |
| `verify.py` | Re-reads a built book and re-checks every puzzle with separate code. Run it before every upload. |

Format: 8.5 x 11 in paperback, black ink on white paper, no interior bleed; cover has 0.125 in bleed and a clear
panel for the barcode. Builds are seeded, so the same command gives the same book.

## Making the next book
1. Add an entry to `BOOKS` in `build_book.py` with a new `seed`, `volume`, `file` and `mix` (how many of each type per part).
2. A new book must be genuinely different from the earlier ones (Amazon removes near-duplicates): change the mix,
   the difficulty, the themes in `content.py`, or make it a single-type book.
3. Pictures for nonograms are hand-picked in `PICTURES` (puzzles.py): render a symbol at the grid size, look at it,
   and add it only if it is recognisable. Do not reuse a picture within a book.
4. Word ladders use everyday words only. After building, read the ladder solutions; add anything crude, obscure or
   a name to `_BLOCK` and rebuild.
5. Build, run `verify.py`, and look through the rendered pages before sending the files to Robin.

`books/out/` is not committed: this repository is public and the PDFs are for sale.
